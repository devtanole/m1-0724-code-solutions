# typescript-promises-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is the Event Queue model of Promises?
  A: JavaScript runtime event loop continuously checks the async operation queue and process the callbacks in the order they arrive
- What are the three states a Promise can be in?
  A: pending, fulfilled, rejected
- How do you handle the fulfillment of a Promise?
  A: with a .then() which takes a callback for when Promise is resolved
- How do you handle the rejection of a Promise?
  A: .catch() with callback for rejections
